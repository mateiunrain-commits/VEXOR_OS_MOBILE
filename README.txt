VEXOR OS MOBILE — instalare pe Google Pixel 10 Pro

FIȘIERE:
- index.html: aplicația
- style.css: designul premium
- app.js: funcțiile și salvarea locală
- manifest.webmanifest + sw.js + icon.svg: instalare PWA și cache offline

TESTARE RAPIDĂ:
1. Deschide index.html într-un browser pentru a testa interfața.
2. Pentru instalare PWA reală, fișierele trebuie publicate pe o adresă HTTPS (de exemplu GitHub Pages).
3. Deschide adresa HTTPS în Chrome pe Pixel.
4. Apasă meniul ⋮ și alege „Instalează aplicația” sau „Adaugă la ecranul de pornire”.

FUNCȚII:
- Navigare mobilă
- Scurtături către Fortnite, Xbox, Minecraft, Steam și Roblox
- Notițe salvate în memoria locală a browserului
- Planificator de sarcini
- Timer Focus cu 5/15/25 minute
- Nume și accent de culoare personalizabile
- Cache offline după prima încărcare completă

LIMITĂRI:
- Nu înlocuiește Android și nu poate controla setările interne ale telefonului.
- Datele rămân în stocarea locală a browserului; ștergerea datelor browserului le poate elimina.
- Site-urile externe și fontul online pot necesita internet.
